# User Manual & Operations Guide

## Role-Based Guide

### 1. Wildlife Researcher
- **Species Recognition**: Upload camera trap images to run YOLOv8 object detection and view bounding box annotations.
- **Audio Recognition**: Upload animal call sound files (.wav/.mp3) to generate waveforms and spectrograms.
- **Observations**: Log field observations with site selection and animal counts.

### 2. Forest & Conservation Officer
- **GIS Map**: View interactive Leaflet map to inspect spatial distribution of species, habitat health scores, and risk markers.
- **Conservation Engine**: Review automated conservation recommendations and generate new site-specific interventions.
- **Executive Dashboard**: Review top-level KPI cards and 12-month population velocity trends.

### 3. Administrator
- **System Health**: Monitor live database size, API latency, CPU/RAM utilization, and model loading status.
- **Multi-Format Reports**: Export comprehensive reports in PDF, CSV, Excel, or JSON format.

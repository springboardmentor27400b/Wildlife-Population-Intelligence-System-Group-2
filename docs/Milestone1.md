# Milestone 1 Documentation

## Objectives
- Initialize the project structure
- Implement authentication and protected routes
- Create monitoring site and survey workflows
- Support image and audio uploads
- Prepare the data model for future AI milestones

## API Summary
- Register and login users
- Manage profile, monitoring sites, surveys, uploads, species, and dashboard statistics

## Workflow
1. Register or login
2. Create a monitoring site
3. Create a survey
4. Upload wildlife image or audio
5. Review dashboard statistics
